# Mes sites

Page d'accueil publiée sur https://antotilm.github.io/ : elle rassemble les liens vers tous mes sites.

- **Ajouter un site** : copier un bloc `<li>` dans `index.html`, puis lancer `publier.bat` depuis `E:\Website`.
- **Voyages** : chaque voyage a sa date de fin (`data-fin`). Une fois la date passée, il descend tout seul dans « Historique ».
- **Filet de sécurité** : un site publié sur GitHub Pages mais oublié ici s'affiche quand même dans « Autres sites » (la page interroge l'API publique de GitHub).
