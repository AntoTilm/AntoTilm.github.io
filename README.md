# Mes sites

Page d'accueil publiée sur https://antotilm.github.io/ : elle rassemble les liens vers tous mes sites.

Pour ajouter un site, copier un bloc `<li>` dans `index.html`, puis lancer `publier.bat` depuis `E:\Website`.

Le dossier `bruges/` est le site du week-end à Bruges, publié sur https://antotilm.github.io/bruges/ directement par ce dépôt (voir `bruges/README.md`).
